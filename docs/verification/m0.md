Why AGP 9.3.3 and Gradle 9.7.1, not the newest:

- Kotlin 2.4.20 to 2.4.21 fully supports Gradle 7.6.3 to 9.7.0 and AGP
  8.5.2 to 9.3.1. Source: the KGP compatibility table at
  https://kotlinlang.org/docs/gradle-configure-project.html
- AGP 9.4 needs Gradle 9.6.0 or newer and supports API 37. AGP 9.3 needs
  Gradle 9.5.0 or newer and supports API 37. Sources:
  https://developer.android.com/build/releases/gradle-plugin and
  https://developer.android.com/build/releases/agp-9-3-0-release-notes
- So the newest set inside the documented Kotlin range is AGP 9.3.x and
  Gradle 9.7.x, latest patches 9.3.3 and 9.7.1. Revisit when Kotlin
  documents AGP 9.4.

Why compileSdk 37: Compose BOM 2026.09.00 pulls foundation 1.12.1, whose
AAR metadata requires compileSdk 37. The first build failed
`checkDebugAarMetadata` on 36. Platform `android-37.0` revision 2 was
installed with `sdkmanager --install "platforms;android-37.0"`.
