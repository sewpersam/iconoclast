## Task 16: offline build

Script `clone_build.sh` in the scratchpad: `git clone --recurse-submodules
--shallow-submodules https://github.com/sewpersam/iconoclast.git`, no
`local.properties`, `ANDROID_HOME` and `GRADLE_USER_HOME` exported, then one
Gradle run. The shallow submodule saves tmpfs; the pinned tree is the same.

| Clone | HEAD | Build | Result |
|---|---|---|---|
| A | d8edf00, submodule 90a43435 | `./gradlew assembleDebug assembleRelease`, online | BUILD SUCCESSFUL in 28s, 230 tasks executed. This is the M0 clean-clone gate and the first sync. |
| B | d8edf00 | `unshare -rn sh -c 'ip link set lo up; ./gradlew --offline assembleRelease'` | BUILD SUCCESSFUL in 28s, 136 tasks executed. |

The first offline attempt in clone B failed before Gradle started. Inside
`unshare -r`, Java took `/root` as home and found no wrapper distribution.
Exporting `GRADLE_USER_HOME` fixed the harness, not the build. The same
unbuilt clone then passed. No build change was needed.

clones. F-Droid's builder must use build-tools 36.0.0, because the template is
built by its `aapt2` and `d8` directly. Platform 37 is also required. A
different JDK vendor was not tried.
