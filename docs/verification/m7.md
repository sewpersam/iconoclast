### The M7 gate: export and import round trip

`ExportRoundTripGateTest.everyGoldenThemeRoundTripsToItsGoldenBytes`: every
golden theme in `GoldenSet.CASES` and `CASES_324` is exported with its
textures and the signing key, read by `ThemeZipImport`, stored by
`ArchiveImport` into an empty install (new texture dir, theme dir, key store)
with `restoreKey = true`, and every golden sample is rendered at its pack
size from the imported document. All 308 PNGs equal their committed goldens.
The key arrives on the first import (`RESTORED`) and is `ALREADY_PRESENT`
after. 7.4 s on the JVM.

Checked broken-first: an import that rewrites stroke weight 1.75 to 1.7,
with the theme-equality assertion disabled, fails 30 renders
(`effects_jade` 6, `preset_jade` 24). With the assertion it fails earlier.

`overridesRoundTripToTheSameBytes`: a document with every override field,
a swap, and an override for a name outside the pin, round-trips its overrides
exactly and renders every slot's effective look to the same bytes.

### Key round trip

`PackKeyBackupTest`: backup then restore into a fresh install gives the same
certificate and private key; the same key twice is `ALREADY_PRESENT`; a
different local key throws `KeyMismatchException` and both its files are
unchanged; a wrong password or a damaged store writes nothing.
`ThemeZipTest.aDifferentLocalKeyStopsTheImport`: the import is refused before
any texture or theme is stored, the phone keeps its key, and the same archive
without `restoreKey` imports the theme and leaves the key alone.
