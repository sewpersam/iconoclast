## Arcticons

- Project: Arcticons by the Arcticons Team and contributors,
  https://github.com/Arcticons-Team/Arcticons
- Source: git submodule at `third_party/arcticons`, pinned to commit
  `90a4343510f35e33421f0a41df5debc29c3604d1`.
- Icons: `icons/white/`, licensed Creative Commons Attribution-ShareAlike
  4.0 International (CC BY-SA 4.0),
  https://creativecommons.org/licenses/by-sa/4.0/
- Component map: `app/src/main/assets/appfilter.xml`, part of the Arcticons
  app, licensed GPL-3.0, https://www.gnu.org/licenses/gpl-3.0.html
- Changes: the icons are converted to a binary geometry bundle at build
  time, then restyled and rasterized on the device. Stroke weight, fill,
  colour, background, textures and effects differ from the originals.

Icon packs generated by Iconoclast contain icons derived from Arcticons.
Those icons are licensed CC BY-SA 4.0 and carry this attribution.

## Iconoclast glyph

- `iconsource/bundled/iconoclast.svg`, a cracked icon tile in Arcticons line
  style, is Iconoclast's own, by the Iconoclast contributors, licensed CC BY-SA
  4.0. It is bundled into every generated pack as the drawable `iconoclast`,
  mapped to Iconoclast's launcher activity by `iconsource/bundled/appfilter.xml`.
  It is not part of Arcticons and is not sent upstream.
- The app's launcher icon (`app/src/main/res/drawable/ic_launcher_foreground.xml`)
  and the store icon (`fastlane/metadata/android/en-US/images/icon.png`) draw
  the same glyph, same licence.

The store graphic `fastlane/metadata/android/en-US/images/featureGraphic.png`
is an Iconoclast render of Arcticons icons in the Jade and Neon presets,
copied from the golden test images. It is a derivative of
Arcticons, licensed CC BY-SA 4.0, with this attribution.

- Project: Geist Sans and Geist Mono by The Geist Project Authors,

- Files: `app/src/main/res/font/geist_*.ttf`, the release's static TTFs,
  unmodified, renamed only to fit Android resource names.
- Licence: SIL Open Font License 1.1, full text in `licenses/OFL-1.1-Geist.txt`.

reference only. No Geist UI code is included.
